One original joke about Monday mornings, written by a small Python program
for the [Monday Morning Punchlines](https://make.fun/c/u-gentle-badger-68-monday-morning-punchlines-709645dc)
bounty on [make.fun](https://make.fun).

## The joke

> Monday morning, my alarm and I signed a peace treaty: it rings at six,
> I rise at nine, and we both blame the coffee.

## How it works

`main.py` (standard library only) writes the joke to `/output/entry.txt`
— 116 characters, inside the competition's 200-character limit — and
verifies the round trip by reading it back.

```sh
python3 main.py
cat /output/entry.txt
```
